1. جدول auth_user (المستخدمون)
═══════════════════════════════════════════════════════════════════════════════════════════════════════════

الوصف: يحتفظ بمعلومات حساب المستخدم الأساسية والمصادقة

┌─────────────────────────┬──────────────────────┬──────────────────────────────┬────────────────────────┐
│ اسم الحقل              │ نوع البيانات        │ الوصف                        │ ملاحظات                │
├─────────────────────────┼──────────────────────┼──────────────────────────────┼────────────────────────┤
│ id                      │ integer              │ معرف المستخدم الفريد        │ مفتاح أساسي (PK)       │
│ username                │ varchar              │ اسم المستخدم (فريد)         │ مطلوب، فريد            │
│ email                   │ varchar              │ عنوان البريد الإلكتروني     │ مطلوب                  │
│ password                │ varchar              │ كلمة السر (مشفرة)           │ مطلوب، مشفر PBKDF2     │
│ first_name              │ varchar              │ الاسم الأول                 │ اختياري                │
│ last_name               │ varchar              │ اسم العائلة                 │ اختياري                │
│ is_active               │ boolean              │ هل الحساب نشط؟              │ افتراضي: true          │
│ is_staff                │ boolean              │ هل المستخدم موظف/مسؤول؟    │ افتراضي: false         │
│ is_superuser            │ boolean              │ هل مسؤول نظام؟             │ افتراضي: false         │
│ last_login              │ timestamp            │ آخر تسجيل دخول              │ اختياري، nullable       │
│ date_joined             │ timestamp            │ تاريخ إنشاء الحساب          │ مطلوب                  │
└─────────────────────────┴──────────────────────┴──────────────────────────────┴────────────────────────┘

ملاحظات مهمة
═══════════════════════════════════════════════════════════════════════════════════════════════════════════

✓ PK (Primary Key): مفتاح أساسي - معرّف فريد لكل صف
✓ FK (Foreign Key): مفتاح أجنبي - يربط الجداول معاً
✓ nullable: يمكن أن يكون القيمة فارغة (NULL)
✓ varchar: نص متغير الطول
✓ bigint: رقم صحيح كبير (64-bit)
✓ integer: رقم صحيح (32-bit)
✓ boolean: قيمة منطقية (true/false)
✓ timestamp: تاريخ ووقت
